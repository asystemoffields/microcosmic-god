## What this work stream did

Extended the sandbox so a controller's *structure* (not just its weights and a
scalar size) is a search dimension, and measured whether richer controllers
earn their keep under task pressure. Four landed pieces, each committed with
tests green (98 tests):

1. **Transfer result** (`transfer/RESULTS.md`). Held-out-world evaluation of
   saved champions vs architecture-matched controls. Optimized controllers
   carry competence into unseen worlds (survival/energy), beating both random
   and structure-destroyed (permuted) controls in 12/12 paired worlds for
   three of four champions; the result is champion-shaped (a profile, not one
   number). Crash-safe harness: `transfer/probe_worlds.py` checkpoints each
   run to JSONL and resumes.

2. **Evolvability audit + program** (`docs/CONTROLLER_EVOLVABILITY.md`).
   Finding: the prior substrate could scale capacity but not change controller
   *shape* — every saved champion sat inside the initialization size range
   (hidden 5–14). Upkeep is charged immediately while extra capacity pays only
   after lifetime learning fills it, so ranking prunes growth before it pays.

3. **Growth-economics fix (validated)**. A developmental subsidy ramps the
   neural component of upkeep over an individual's first N ticks
   (`--neural-grace-ticks/-floor`, config defaults off). Capacity demography
   (`analysis/capacity_demography.py`, 3 seeds/arm, 3000 ticks) shows it opens
   the **17–48 capacity corridor**: 2.65× more mid-capacity individuals,
   +90% reproduction, baseline undistorted; large-but-random controllers still
   fail. Read: the cost barrier is a staircase, and the subsidy opens exactly
   the rung that stepwise structural growth climbs through.

4. **Typed modular controller** (`microcosmic_god/modular.py`, fully wired).
   Typed observation tokens → per-type encoders → K recurrent blocks with a
   float wiring matrix → gated heads. Capacity is owned by structure; the
   genome's size budget follows it. Variation operators: `duplicate_block`
   (copy + halve both gates — exactly behavior-preserving), `add_block`
   (enters zero-gated — exactly behavior-preserving), `prune_block`. So a
   structural change to a candidate is survivable rather than lethal. Also
   per-block plasticity scales and a context-computed learning gate (neutral
   at birth). Seed with `--modular-fraction` / `--modular-max-blocks`;
   `--structural-rate` sets how often a clone takes a structural step. Legacy
   single-block controllers import as K=1. Aggregate logs now include an
   architecture census (block counts, active blocks, capacity, learning-gate
   spread) — `analysis/architecture_trajectory.py`.

## Candidate world features (to make richer controllers earn their keep)

Design rule: add a feature only if a larger/structured controller can exploit
it and a minimal one cannot; add one at a time so the architecture census can
attribute any change. Ranked:

1. **Signal-reliability dynamics.** The signal/mark channels already exist but
   carry no enforced meaning. Make a signal payoff-relevant (predicts a nearby
   resource or hazard) and let its reliability vary — so conditioning behavior
   on *which* signalers have been reliable becomes a learnable competence.
   This is standard costly-signaling / cheap-talk game theory; multi-agent
   inference is the classic driver of larger working memory. Highest ceiling,
   and cheap because the channels exist — mostly a payoff contract.
2. **Depleting + regenerating resource patches.** A foraged patch recovers
   slowly; the efficient policy is route rotation, which needs spatial-temporal
   memory of where/when you last visited. Cheap (a recovery timer), immediate
   memory pressure.
3. **Delayed-payoff causal challenges.** The existing affordance chains pay on
   completion; a variant where a step pays K ticks later exercises credit
   assignment across a temporal gap — i.e. the prediction heads and recurrence.
